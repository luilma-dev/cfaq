# Identidade visual

## Marca

**CFAQ**. Assinatura: **Estude. Evolua. Conquiste.**

A referência fornecida pelo idealizador define um wordmark sóbrio, azul-marinho, com o A sugerindo uma direção. A aplicação interpreta a marca em texto e usa uma rosa dos ventos simples como símbolo auxiliar. O conjunto comunica rumo, clareza e preparação.

## Cores

| Uso                         | Cor       |
| --------------------------- | --------- |
| Primária, confiança         | `#0B2A5B` |
| Ação e destaque             | `#3B82F6` |
| Fundo suave                 | `#F8FAFC` |
| Superfície                  | `#FFFFFF` |
| Texto secundário            | `#64748B` |
| Verde brasileiro e acerto   | `#157A55` |
| Amarelo brasileiro, detalhe | `#F4C542` |
| Aviso e erro                | `#A64032` |

Verde e amarelo aparecem em pequenos detalhes. Não usar bandeiras, brasões ou insígnias oficiais. Botões de ação usam azul-marinho para manter bom contraste com texto branco; azul vivo aparece em realces e indicadores.

## Tipografia e composição

Manrope em títulos, DM Sans em texto. Arquivos de fonte acompanham o pacote e não dependem de carregamento externo durante o estudo. Fallback de sistema se ocorrer falha no carregamento.

Superfícies claras, bordas discretas, espaçamento confortável e cantos arredondados. Conteúdo legível antes da decoração. Navegação inferior no celular e lateral em telas largas. Interface totalmente em português brasileiro.

## Acessibilidade

Alvos de toque de pelo menos 44 pontos. Respostas apresentam texto e ícone além da cor. Elementos interativos recebem rótulos e estados para tecnologias assistivas. Texto respeita escala do sistema. O app não depende de animações para comunicar mudanças.
